# FLUDD Village - updates

This repository only holds the releases the FLUDD Village launcher checks for its updates.

FLUDD Village is a fan-made mod for Resident Evil 4 (2005, Steam): you play as Mario with FLUDD, his models, animations and sounds read while the game runs from your own copy of Super Mario Sunshine (and, if you want, Super Mario 64). No game files are included: you need your own copies of the games.

> **Work in progress.** Expect bugs and parts of the game that don't work well with Mario yet.

Not affiliated with Nintendo or Capcom.
